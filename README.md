Minion Expression Detector

A real-time facial expression recognition project that turns your face into a Minion! 

What is this?

Ever wondered what your face would look like as a Minion?
This project uses Python, OpenCV, and MediaPipe to track facial landmarks in real time and recognize different facial expressions.

🧠 How It Works

The program processes webcam frames in real time and:

📷 Captures video from the webcam
🔍 Detects facial landmarks using MediaPipe Face Landmarker
📐 Analyzes landmark positions and facial geometry
🧩 Uses threshold-based rules to classify expressions
🍌 Maps the detected expression to a Minion visual
